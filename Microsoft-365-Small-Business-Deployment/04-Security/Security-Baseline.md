# Microsoft 365 Security Baseline Checklist

Use this as a review checklist, not a claim of compliance.

## Identity and access
- [ ] MFA strategy selected and tested
- [ ] Conditional Access licensing verified, if used
- [ ] Privileged roles minimized
- [ ] Separate admin identities considered
- [ ] Emergency access procedure documented and tested
- [ ] Guest accounts and access reviewed
- [ ] Joiner/mover/leaver process documented

## Email
- [ ] SPF reviewed
- [ ] DKIM enabled for custom domain where supported
- [ ] DMARC monitoring and enforcement plan documented
- [ ] Anti-spam/anti-phishing settings reviewed
- [ ] Shared mailbox permissions reviewed
- [ ] External sender awareness considered

## Collaboration and data
- [ ] SharePoint site owners assigned
- [ ] Department access tested
- [ ] External sharing set to business need
- [ ] OneDrive sharing and retention expectations documented
- [ ] Teams owners and guest settings reviewed

## Devices (only if licensed/in scope)
- [ ] Intune enrollment approach documented
- [ ] Device compliance requirements reviewed
- [ ] Endpoint protection settings reviewed
- [ ] Lost/stolen device procedure documented

## Monitoring and operations
- [ ] Sign-in and audit logs reviewed
- [ ] Alerting/monitoring responsibilities documented
- [ ] License assignment process documented
- [ ] Change management and rollback process documented
- [ ] Periodic access review schedule defined

Record **Implemented**, **Not implemented**, **Not applicable**, or **Not tested** for each item, with evidence and a remediation owner.
