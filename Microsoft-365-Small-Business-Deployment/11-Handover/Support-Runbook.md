# Support Runbook

## Common request: password or sign-in issue
1. Verify the requestor using the approved identity-verification process.
2. Check service health and relevant sign-in logs.
3. Confirm account status, license, group membership, and authentication methods.
4. Apply the approved reset/recovery process.
5. Never request or record the user's password or MFA code.
6. Validate recovery with the user and document the result.

## Common request: access to SharePoint/Teams
1. Confirm business owner approval.
2. Check group membership and resource permissions.
3. Add access using the approved group model.
4. Test access and record the change.
5. Set a review date for temporary access.
