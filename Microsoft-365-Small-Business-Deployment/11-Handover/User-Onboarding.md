# User Onboarding Runbook

1. Receive an approved onboarding request.
2. Verify name, role, department, manager, start date, and required access through an approved channel.
3. Create the Entra ID account using the naming convention.
4. Assign the minimum required license.
5. Add the user to approved groups.
6. Configure/register authentication methods according to the identity policy.
7. Grant access to mail, Teams, SharePoint, and OneDrive as required.
8. Validate sign-in and required services.
9. Provide user instructions through an approved channel.
10. Record completion and notify the requestor.

## Checklist
- [ ] Request approved
- [ ] Account created
- [ ] License assigned
- [ ] Groups/access assigned
- [ ] MFA/authentication registration complete
- [ ] Service access validated
- [ ] Completion recorded
