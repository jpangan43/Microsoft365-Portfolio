# Entra ID User Provisioning

## Naming convention
Use a consistent format such as `firstname.lastname`. Do not include real personal information in public examples.

## Procedure
1. Open https://entra.microsoft.com/ and navigate to **Users → All users**.
2. Create a pilot user with fictional details.
3. Assign only the license required for the pilot.
4. Add the user to the relevant department and policy pilot groups.
5. Register approved authentication methods.
6. Validate sign-in, MFA, license/service access, and group membership.
7. Record the outcome without storing temporary passwords or authentication secrets in this repository.

## User lifecycle checklist
- [ ] Request approved
- [ ] Unique identity created
- [ ] Required groups assigned
- [ ] License assigned
- [ ] Authentication methods registered
- [ ] Access validated
- [ ] Manager/owner informed

## Test users
Use lab-only identities and label them clearly. Never publish real user UPNs in screenshots.
