# OneDrive Configuration and Governance

## Purpose
Use OneDrive for an employee's individual work files and controlled sharing. Use SharePoint for team-owned/shared content.

## Configuration checklist
- [ ] Review tenant sharing settings
- [ ] Review default link type and link permissions
- [ ] Review external sharing policy
- [ ] Confirm storage and sync expectations
- [ ] Document known-device and access requirements if applicable
- [ ] Document employee departure and file ownership/retention process
- [ ] Test upload, sync, and sharing with synthetic data

## Offboarding considerations
Follow organizational policy and current Microsoft guidance when preserving or transferring a departing user's data. Confirm retention, legal hold, and licensing implications before removing licenses or deleting accounts.
