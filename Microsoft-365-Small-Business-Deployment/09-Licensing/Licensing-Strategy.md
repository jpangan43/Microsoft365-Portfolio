# Licensing Strategy

Licensing must match user needs, security requirements, geography, and current Microsoft product terms. Confirm current eligibility, feature availability, and pricing directly before a real purchase.

## Example planning matrix

| User type | Candidate license | Reason to evaluate |
|---|---|---|
| Standard employee | Business Basic, Standard, or Premium | Select based on desktop apps, security, and device needs |
| IT/security administrator | Appropriate qualifying plan | Verify admin and security feature requirements |
| Frontline/temporary worker | Eligible plan matching usage | Check service and user eligibility |
| Shared mailbox | Often no separate license within applicable limits | Review size, archive, hold, and feature requirements |

## Evaluation criteria
- Desktop Office apps required?
- Exchange mailbox and storage needs?
- Conditional Access required?
- Intune/device management required?
- Defender security features required?
- External/guest collaboration needs?
- Shared mailbox limits and retention requirements?
- Number of users and budget?

## Important
Do not assume every user needs the same license, or that a trial includes every required feature. Conditional Access commonly requires Microsoft Entra ID P1 or a qualifying Microsoft 365 subscription. Verify current Microsoft licensing documentation.
