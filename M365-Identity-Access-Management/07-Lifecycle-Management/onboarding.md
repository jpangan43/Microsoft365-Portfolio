# Employee Onboarding Runbook

## Required approval information

- Employee name and start date
- Department, job title, manager, and employee type
- Required license and applications
- Approved groups and resource access
- Request/approval reference

## Procedure

1. Receive and validate the approved onboarding request.
2. Check for an existing account to prevent duplicates.
3. Create the user using the approved naming convention.
4. Populate attributes used for dynamic membership and access policies.
5. Assign the approved license and group memberships.
6. Grant access to required applications and resources.
7. Ensure authentication registration and MFA requirements are applied.
8. Deliver initial sign-in instructions through an approved secure channel.
9. Test sign-in and required access with the user or designated test account.
10. Record completion, approver, date, access granted, and exceptions.

## Completion checklist

- [ ] Approval verified
- [ ] Correct identity and attributes
- [ ] License assigned
- [ ] Group and resource access verified
- [ ] Authentication requirements verified
- [ ] User/manager notified
- [ ] Evidence and change record updated
